# حزمة تنفيذ إعادة تصميم واجهات NIRAB

افتح `NIRAB_CUSTOMER_UI_UX_EXECUTION_PLAN.md` أولًا. يحتوي على المواصفة والمراحل والقيود ومصفوفة القبول ورسالة بدء جاهزة للوكيل في القسم 12.

الحزمة تضم الخطة نفسها و20 صورة مرجعية أرسلها المستخدم، وفهرسًا يربط أسماءها الجديدة بأسمائها الأصلية. الصور لم تُعدّل؛ هي مراجع لفهم التنظيم البصري، وليست أصولًا مسموحًا تضمينها في التطبيق.

يمكن إعطاء الوكيل مسار هذه الحزمة بجانب المشروع المحلي، أو وضع الخطة داخل `docs/rui/` مع إبقاء مجلد `references/` بجانبها لكي تعمل روابط الصور. لا تضف الصور إلى أصول Flutter أو مستودع عام تلقائيًا. لا تحتوي الحزمة على مصدر المشروع أو مفاتيح أو ملفات خطوط.

**اختبار Android على الهاتف الحقيقي المتصل باللابتوب فقط؛ المحاكي ممنوع.** تشغيل الويب مسار تحقق مستقل، لا بديل لاختبار التطبيق الفعلي.

هذه حزمة تخطيط وتسليم للوكيل؛ لا تتضمن ادعاءً بأن الشيفرة عُدلت أو أن جهاز المستخدم اختُبر بالفعل.
