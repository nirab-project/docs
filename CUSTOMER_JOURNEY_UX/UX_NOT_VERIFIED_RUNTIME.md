# UX — سجل ما لم يُتحقق منه تشغيلياً

التاريخ: 2026-10-07. المنع صريح في خطة الست مراحل؛ هذا السجل ليس تفويضاً لتشغيل أي عنصر.

| العنصر | الحالة والسبب | ما لا يجوز استنتاجه من الفحص الساكن |
|---|---|---|
| Laravel والخادم/العمال/المجدول وRedis/Docker | لم تُشغّل | لا إثبات boot أو queue أو routes runtime |
| قواعد البيانات/MySQL Spatial | لا اتصال أو تغيير | لا إثبات توافق مخطط قاعدة قائمة أو هندسة تغطية بيانات فعلية |
| المهاجرتان الجديدتان | مكتوبتان، php -l ومراجعة المصدر فقط، غير مطبقتين | لا إثبات DDL على نسخة قاعدة ولا rollback فعلي |
| اختبارات Unit/Integration/E2E | لم تُشغّل ولم تُضف بدائل تشغيلية | لا إثبات سيناريوهات حجز فعلية |
| Flutter run/build والمتصفح والمحاكيات والأجهزة | لم تُشغّل | لا إثبات منظر أو RTL أو safe area أو keyboard أو accessibility/permissions على جهاز |
| الدفع النقدي/المحفظة/Offline/بوابة البطاقة | تتبع العقود فقط | لا عملية دفع ناجحة أو خصم/رد فعلي؛ لا عودة من رابط تثبت paid |
| التزامن وفقد الاتصال | أقفال ومعاملات ومفاتيح ومراجعة مسارات | لا إثبات سباقات استهلاك الرصيد أو deadlocks تحت الحمل أو فشل الشبكة على جهاز |
| Odoo/ZATCA والفاتورة/PDF الخارجي | API الحالي محفوظ | لا فاتورة مُصدرة أو مرسلة أو تسوية مثبتة |
| الإشعارات وSMS وWhatsApp وMaps والمحادثة | لم تستدع خدمات خارجية | لا إثبات وصول push أو دقة ETA أو صلاحيات الموقع |
| تجديد الباقات وشراء/شحن المحفظة | العقود الحالية، UI الربط فقط | لا مجدول يعمل ولا تجديد بطاقة تلقائي |
| رفع الصور والمرفقات المحلية/S3 وBlade | تدقيق نصي فقط | php -l ليس تجميع Blade أو اختبار رفع/عرض |
| صلاحيات المستخدمين الفعلية | شروط المصدر وملكية السجلات راجعت | لا مصفوفة أدوار تشغيلية أو بيانات إنتاج جرى اختبارها |
| نشر/رفع Git | لم يُنفذ | commits محلية فقط، لا deployment أو push |

## حدود مقصودة مستمرة

- F06: النقل والاستلام والإرجاع مرحلة سابعة مشروطة خارج الست، لم تُبنَ ولم يُعلن إغلاقها.
- لا شراء باقة مباشر بالبطاقة، ولا باقة مع دفع فرق، ولا تحويل quote/متكرر إلى زيارة مغطاة؛ خطة 4/8/12 الحالية محفوظة.
- تغيير زيارة مغطاة يستلزم إلغاء مؤهلاً قبل بدء العمل ثم حجزاً جديداً، لا إعادة جدولة تتجاوز أهلية الباقة.
- Pending confirmation للحجز المباشر محفوظ في الذاكرة؛ زيارة الباقة تحفظ مفتاحها وpayload المحدود عبر إعادة تحميل التطبيق. مراجعة قائمة الحجوزات ضرورية عند فقد سياق المحاولة؛ لا وعد باستعادة طلب مباشر بعد مسح بيانات الجهاز.
- 28 ملاحظة Dart من نوع info (19 عميل، 1 فرع، 8 فني)، معظمها أقواس أسلوبية/import زائد وnull-aware elements؛ لا أخطاء أو warnings في نطاق الملفات المحللة.
- فحص الأسرار نمطي على الإضافات مع مراجعة الملفات المحمية؛ ليس بديلاً لتدقيق أمني شامل. لم تتغير ملفات الأسرار أو APP_KEY أو الاعتماديات/lockfiles أو brand_tokens/الخطوط.
