# UX — نموذج إعداد المحتوى لاحقاً

التاريخ: 2026-10-07. قائمة تسليم للإدارة؛ لم تُدخل بيانات في قاعدة ولا تُشغّل Seeder. تملأ كل خانة من معلومات نيراب المعتمدة فقط. تبقى هوية main والألوان والخطوط كما هي.

## سجل لكل خدمة

| الحقل | مصدر التحرير الحالي | المطلوب قبل إتاحته للعملاء |
|---|---|---|
| التصنيف الرئيسي والفرعي | إدارة التصنيفات | اسم عربي/إنجليزي، الحالة والترتيب، ربط المنطقة الصحيح |
| اسم الخدمة/slug | إدارة الخدمات | اسم واضح، slug ثابت للروابط قدر الإمكان، ترجمتان |
| pricing_type | الخدمة | fixed أو quote وفق نموذج تقديم الخدمة الفعلي؛ لا إدخال quote في السلة |
| الوصف الغني | HTML الخدمة الحالي | وصف العمل، ما يشمله، ما يستثنيه، احتياجات المكان، حدود التنفيذ؛ أقسام عند وجود محتوى معتمد فقط |
| المدة والتنفيذ | estimated_duration_minutes / execution_type / default_technicians | مدة تنفيذ معقولة، فردي/فريق، العدد المطلوب، مطابقة مهارات الفريق |
| الوحدات والخيارات | variations وvariant_key لكل zone | اسم الوحدة، مفتاح ثابت، سعر/ضريبة الخدمة الثابتة من الإدارة، حد كمية مناسب |
| الحقول الديناميكية | service fields/options/validation_rules | label عربي/إنجليزي، type/unit، required، min/max والخيارات؛ لا سؤال بلا ضرورة |
| FAQ | أسئلة الخدمة القائمة | أسئلة وأجوبة عربية وإنجليزية، النطاق والتوقعات والقيود؛ لا جدول موازٍ |
| الصور | thumbnail/cover + gallery الجديد | صور يحق لنيراب استخدامها، ترتيب واضح، حتى 12 صورة gallery من jpg/png/webp بحد الرفع الحالي؛ fallback لا يعوض جودة المحتوى |
| الفروع والتغطية | service areas/availability/category/zone | فرع نشط معتمد، خدمة وتصنيف متاحان، مضلعات MySQL Spatial صحيحة وسعة وساعات عمل |
| العمالة والموعد | shifts/leaves/skills/team الحالي | مهارات الخدمة وتوفر فنيين/فريق وقائد، ساعات تغطي المدة، سعة فعلية |
| أهلية الباقة | VisitPlan الحالي | fixed فقط، 4/8/12، max_units_per_visit، cadence والحد الأدنى بين الزيارات، validity_days تغطي الزيارات، السعر/العملة وحالة الخطة |
| عروض الأسعار | عمل الفرع الحالي | offered_price والمدة والعمالة والنطاق والشروط والصلاحية؛ معاينة مجانية/مدفوعة فقط عند الحاجة الفعلية؛ إثبات paid_at قبل خصم رسومها |
| الترويج | البنرات والحملات والكوبونات الموجودة | وصف مطابق لقواعد الخادم؛ لا وعد بخصم تراكمي أو ضمان أو اعتماد لم يوثق |

## إعدادات تشغيل قائمة يلزم التحقق منها لاحقاً

- وضع الفروع وbidding_status حسب سياسة التشغيل الحالية؛ القائمة تعرض طلبات العرض لكن API ما زال يحترم تعطيل الميزة.
- طرق الدفع المتاحة والمحفظة وسياسة Guest Checkout؛ شراء الباقة بالمحفظة فقط، وauto_renew هو تفضيل للمحرك الموجود وليس تفويض بطاقة جديداً.
- المنطقة الزمنية للخادم، حدود/تغطية المنطقة والعنوان، السعة، مهارات الفنيين وإجازاتهم. وقت العميل المبدئي لطلب العرض تفضيل لا حجز.
- صلاحيات packages.manage/pricing.manage والموظفين ونطاق الفروع، وضوابط الاطلاع على البيانات الشخصية/المالية القائمة.
- إعدادات الأدلة وOTP والفاتورة الخارجية وصفحات الدعم والعناوين والمحفظة. لا مفاتيح أو بيانات عملاء في هذه الوثائق.
- سياسات الاحتفاظ بالصور: إزالة مرجع gallery لا تحذف الملف آلياً؛ تنظيف غير المشار إليه عمل تشغيل مستقل.
- فحص RTL والهاتف والويب بعد اعتماد تشغيل البيئة؛ هذه القائمة لا تثبت العرض المرئي.
