## القرارات التي تحفظ سلامة المسار

- الخادم مصدر السعر والصلاحية والملكية والرصيد والسعة. سعر الرابط مهمل؛ عدم وجود عقد خادمي واضح يعطّل تأكيد العرض.
- زيارة الباقة تُنشأ وتغطّى في نفس transaction وتستخدم prepaid_visit مباشرةً. قفل العميل والفرع والحجز/الباقة وربط usage/migration يحمي إعادة الطلب؛ الإلغاء المؤهل يعيد الرصيد مرة واحدة.
- تعديل موعد/عنوان/وحدات/خدمة زيارة مغطاة يتم بإلغاء مؤهل ثم حجز جديد؛ مسارات التعديل القديمة لا تلتف على هذا الشرط، والواجهات التشغيلية تراعيه.
- النتيجة غير المحسومة للدفع أو التأكيد لا توصف بأنها فشل أو تحصيل مثبت. إعادة المحاولة تستخدم الطلب السابق وتوضّح ذلك. Offline والفاتورة مستقلان عن التنفيذ.
- workflow المضاف يرسل معرف الباقة وحالة تغطية الزيارة فقط للمتابعة؛ لا يعرض سعر شراء الباقة أو رصيد محفظة العميل للفرع/الفني. ضوابط الصلاحيات القائمة لم تُعطّل.
- MySQL 8/Spatial ومحركات FAQ والباقة والمحفظة والمواعيد والدفع والمحاسبة محفوظة؛ لا اشتراكات/عمولات مزودين معادة ولا محرك موازٍ.
