# نص جاهز لبدء تكليف وكيل التطوير

أنت وكيل التنفيذ في مشروع NIRAB Clean. هذه الحزمة هي عقد التنفيذ الكامل لإعادة تصميم نواة الخدمات والسلة والجدولة والطلبات والتسعير والباقات وعروض الأسعار وتشغيل الفروع، مع تعديل Backend Laravel وCustomer Flutter وProvider Flutter وServiceman Flutter ولوحتي الإدارة والفرع.

**ابدأ بفك ضغط الوثائق داخل مساحة العمل وقراءة:**
`README.md`، `00-START-HERE.md`، `01-AGENT-EXECUTION-CONTRACT.md`، `02-SOURCE-AUDIT.md`، `03-DECISIONS-AND-SCOPE.md`، `04-REQUIREMENTS-TRACEABILITY.md`، ثم جميع `specs/` و`contracts/` قبل تعديل الكود. اعتمد أرشيفات المصدر الأربعة أو المستودعات المكافئة، وسجل اختلافات النسخ إن وجدت.

نفذ المراحل من `phases/00-PHASE-INDEX.md` واحدة بعد الأخرى، واكتب تقريراً لكل مرحلة باستخدام `templates/PHASE-REPORT.md`. لا تنتقل لمرحلة إذا بقي نقص يمنع تحقيق بوابتها. احفظ العقود والاختبارات والمستندات متزامنة مع التعديلات. لا تكتفِ بشاشات شكلية أو كود غير متصل بدورة تشغيل حقيقية.

**قواعد التشغيل:** PH-00 حتى PH-11 *code-only* دون تشغيل قاعدة أو Docker أو Flutter أو موقع أو API أو migrations أو seed أو تثبيت اعتمادات أو اختبارات. يجوز كتابة كل اختبارات وحدات ومتكاملة مؤجلة التنفيذ. عند إغلاق بوابة CODE-READY انتقل إلى PH-12 المستقلة لتجهيز بيئة Docker محلية معزولة، اختبار Backend وMySQL spatial ولوحتي الويب وتطبيق Flutter Web، وبناء/اختبار تطبيقات Android بحسب الأدوات المتاحة؛ لا تستخدم أسرار الإنتاج ولا ترتبط بخدمات دفع أو رسائل أو Odoo أو Google الحقيقية. عالج الأخطاء المكتشفة وأعد الاختبارات حتى توثق النتائج الفعلية.

**حظر صارم:** لا تدخل VPS ولا تنفذ migration أو reset أو seeder على الإنتاج. لا تدفع تغييرات إلى Git main أو فرع يفعّل Dokploy auto-deploy. احتفظ بمفاتيح التكامل والتهيئة والمدن/حدودها والفروع/حساباتها الداخلية، وصنّف البيانات التشغيلية القابلة للحذف حسب خريطة الحفظ. نفذ أدوات dry-run وreset قابلة للتطبيق لاحقاً بواسطة المالك **لكن لا تشغلها إلا محلياً في PH-12 على بيانات صناعية**. لن ننفذ التحويل الحقيقي إلا يدوياً مع المالك على VPS بعد التسليم.

**التسليم:** كود المشاريع الأربعة المعدل، ملفات migrations/seeders وأوامر الحفظ والتصفير المدروسة، ملفات Docker الاختبارية، العقود الفعلية، تقارير PH-00..PH-12، أدلة الاختبارات والصور/السجلات المنقحة، مصفوفة المتطلبات، قائمة الحالات المتبقية، ودليل خطوات VPS للمالك فقط. حالة التنفيذ عند التسليم `PRODUCTION_NOT_TOUCHED` ما لم يصدر إذن جديد منفصل.

إذا واجهت قراراً جوهرياً غير مغطى أو وجدت تناقضاً بين وثيقة والمصدر، لا تنفذ حلاً صامتاً؛ وثّق الانحراف والمبرر وأثره واختباراته في `templates/DEVIATIONS.md` مع الحفاظ على الأهداف الأساسية.
